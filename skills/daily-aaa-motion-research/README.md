# $shamz Daily Motion Research

A $shamz skill in the Shamz agent-skills collection. It studies the best motion websites daily against a locked design vision, writes delta-only notes, and keeps proven techniques strictly separate from speculation. Research only: it never builds or pushes anything.

## What it does

1. Reads the locked design vision first, verifying its recorded path before every run.
2. Reads the existing research notes so nothing already covered is repeated.
3. Searches the web for current, sourced techniques and real motion websites.
4. Files each new technique under pipeline, camera, particles, interface, game feel, or budgets.
5. Splits every note into PROVEN, with source and date, and SPECULATION, labelled as such.
6. Ends each note with one concrete, testable next step that could be tried as a small preview first.

## What you need

- A locked design vision file in your workspace, with its path recorded in your notes.
- A dated folder of past daily research notes to check against.
- Web search access for current techniques and live motion sites.

## How a run works

1. Verify the vision path, read the vision, then read the past notes.
2. Study the day's sources and pick out only what is new.
3. Write the delta-only note, split PROVEN versus SPECULATION, with sources and dates.
4. End with one testable step, file the note dated, and stop. No build follows.

## Rules it follows

- Research only: no build, no rebuild, no push, no change to a locked decision.
- No technique is called proven without a named source behind it.
- Delta-only notes: repeats are linked to, not re-filed.
- A stale vision path is fixed in the record before the run, never worked around silently.
